# v0.5.0 — Live Agent Brain observatory

This release turns the read-only diagnostics dashboard into a live execution
observatory while preserving Codex as orchestrator and GitHub as durable state.

- v5 retained events and results project into bounded, privacy-filtered live
  nodes, edges, states, handoffs, signals, and chronological evidence.
- The accessible Agent Brain renders observable activity across stable semantic
  regions and never claims to display private reasoning.
- The execution microscope explains normalized identity, timing, activity,
  criterion evidence, and durable references.
- The Strategy Lab compares aligned runs and reports separate cohort measures
  with numerator, denominator, exclusions, and source—never a composite score.
- Optional attributed annotations remain read-only.
- The qualified route fixture deterministically binds the intended Qwen3.8
  reviewer route without changing operator configuration.

Production promotion refreshes the immutable Python runtime and dashboard unit
while explicitly retaining the installed v5 worker. The promotion backup holds
the prior runtime target and service unit for rollback.
