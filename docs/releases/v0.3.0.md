# v0.3.0 — truthful workflow projection

This release replaces the misleading ten-box linear dashboard with a delivery
milestone lane, attached activity/evidence facts, and an explicit numbered
correction loop.

The source workflow ledger remains version one and append-only. The version-two
read projection preserves missing milestones as pending, retains malformed and
conflicting evidence as diagnostics, reports stale publication order and GitHub
label divergence, and keeps the v0.2.0 implementation as the rollback profile.

Both Codex and worker wrappers publish through the same strict observation CLI.
New publication rejects event-id reuse, identity changes, stale writes, illegal
milestone regressions, and invalid correction cycles. Publication remains
best-effort and has no authority over the work outcome.

Qualification includes the observed issue #35 evidence-first case, an ordinary
delivery path, a correction loop, malformed/conflicting inputs, responsive and
reduced-motion rendering, and live refresh coverage.
