# v0.1.3 — live worker publication

The stable worker projects finalized local usage into the normalized run
ledger and publishes issue-bound lifecycle and workflow transitions under one
run identity. The dashboard's local-token total advances when each worker run
finalizes.

Publication is append-only and idempotent. A telemetry failure never changes
the worker exit status; it is emitted to stderr and retained in a sanitized
publication-failure ledger for dashboard visibility. Timeouts and interrupts
remain non-success states.

Promotion preserves the frozen baseline and writes a private rollback backup
before the v4 candidate replaces the installed stable worker implementation.
