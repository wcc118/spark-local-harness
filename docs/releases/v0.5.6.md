# v0.5.6 live OpenCode operator console

The diagnostic dashboard now has a separately authenticated raw operator mode
for exact OpenCode sessions. It renders bounded dialogue, reasoning, tool, and
error events; distinguishes active generation from pending questions and
permissions; and forwards native question and permission decisions only after
live run/session/request validation.

Permission cards show requested and durable patterns plus the winning
server-resolved policy rule. Decisions append attributed audit evidence.
Diagnostic snapshots remain public and read-only; control credentials live
only in per-tab browser session storage and a mode-0600 host token file.
