# v0.5.2 truthful worker activity

This release removes the hidden catch-all Bash denial applied to sandboxed
coders and stops the disposable reviewer configuration from disabling all
read and shell inspection. Existing external-directory, edit, Git mutation,
GitHub, and delegation boundaries remain role-specific.

The live brain now derives active tool calls and tool errors directly from the
retained OpenCode event stream, so preterminal zero-valued health evidence can
no longer conceal real worker activity or permission failures.
