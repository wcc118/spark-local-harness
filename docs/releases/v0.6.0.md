# v0.6.0 — paired-model evidence routing

Issue #134 adds a reproducible ten-case software-engineering benchmark, retained
raw OpenCode evidence, correctness-first paired comparison, and a responsive
dashboard comparison view.

The production qualification run compared identical source, task, check, and
permission identities. Coder Next passed 10/10 objective checks in 604 seconds.
Qwen 3.8 timed out on 10/10 in 1,983 seconds. Qwen remains available through
explicit experimental tiers but is removed from helper, coder, and reviewer
defaults. The result is evidence for this runtime/configuration, not a universal
claim about the base model.

The reviewer runtime now allows repository reads and non-mutating tests in its
read-only checkout while continuing to deny edits, writes, delegation, external
directories, and GitHub mutations.
