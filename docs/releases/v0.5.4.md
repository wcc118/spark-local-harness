# v0.5.4 bridged tool accounting

Canonical health now counts the pending, running, and terminal updates emitted
for one OpenCode tool `callID` as one call. Repeated error updates for the same
call likewise count as one tool error. Legacy events without a call ID retain
their historical one-event-per-call interpretation.

External timeout and interruption paths also revoke the ephemeral session
credential and remove its file while preserving the non-secret control record.
