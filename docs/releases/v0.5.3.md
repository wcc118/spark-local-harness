# v0.5.3 OpenCode session bridge

This release adds an opt-in native OpenCode server transport for local workers.
With `CODEX_LOCAL_SESSION_BRIDGE=1`, a worker runs inside its existing Docker
sandbox through an authenticated loopback `opencode serve` session. The bridge
starts the prompt asynchronously, retains bounded session events in the normal
run JSONL, preserves pending permission requests, and writes a mode-0600
run/session control descriptor for the dashboard permission broker.

The legacy `opencode run` transport remains the default rollback path until the
dashboard controls complete end-to-end qualification.
