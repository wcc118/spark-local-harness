# v0.5.5 deterministic dual-model routing

The harness now owns the single-model DGX vLLM lifecycle. Standard Qwen3.8
workers and complex Coder Next workers select an allowlisted model, wait for
its exact `/v1/models` identity, and hold one lock across selection and the
entire inference run so another worker cannot swap the endpoint underneath it.

Promotion installs the vLLM-only route configuration and model manager and
backs up both for rollback. Interrupted bridge sessions also close an active
control descriptor even when the parent shell receives an interactive signal.
