# v0.2.0 — session-aware diagnostic accounting

This release separates concurrent Codex sessions in durable workflow state and
adds provenance-labelled division-of-labor accounting without ingesting prompt
or response content.

Highlights:

- workflow identity is keyed by session, repository, and operation;
- exact GitHub issue links and all-session/per-session dashboard views;
- start/finish Codex token-counter deltas with reset and missing-data diagnostics;
- local cached-input accounting that distinguishes unsupported from observed zero;
- processed-context, generated/reasoning, and operational contribution views;
- checkout-only container confinement for OpenCode workers.

Qualification evidence: 286 unit/integration tests plus a two-session,
same-issue, process-restart reconstruction smoke test. Local reviewer attempts
did not emit a verdict; Codex therefore performed the final escalated review.
