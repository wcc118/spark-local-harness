# v0.1.1 — live diagnostic participation

This patch connects the `v0.1.0` diagnostic scaffold to live append-only
ledgers and adds a real-time workflow view without changing orchestration or
merge authority.

## Changes

- Server-Sent Events push source-ledger changes to connected browsers.
- Live and replay modes are explicitly labeled.
- A workflow diagram shows the current operation stage, state, correction
  cycle, model/role identity, and stop reason.
- Local workers automatically emit bounded workflow events for coder,
  reviewer, and helper stages.
- Source freshness, missing files, and malformed ledgers are visible.
- Recorded frontier tokens are separated from local tokens.
- Codex context and plan data carry `measured`, `operator-reported`, or
  `unavailable` provenance; the harness never invents these values.

The dashboard remains GET-only. The application binds only to loopback; LAN
exposure is a separate explicit proxy decision on the trusted proving-ground
network.
